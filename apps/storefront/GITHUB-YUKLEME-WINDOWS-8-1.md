# GitHub'a yükleme (GitHub web ile)

1. Bu ZIP'i çıkarın.
2. GitHub reposunda `Add file > Upload files` seçin.
3. Çıkardığınız `RUTH-ISTANBUL-WEBSITE-VERCEL` klasörünün **içindeki** dosya ve klasörleri yükleme alanına sürükleyin.
4. Alttaki kutuya `Ruth Analytics V2 ve SQL kurulumu` yazın.
5. `Commit changes` butonuna basın.
6. Vercel otomatik deploy edecektir.

Not: GitHub web çok sayıda dosyada zorlanırsa Windows 11 bilgisayarda GitHub Desktop ile yükleyin.

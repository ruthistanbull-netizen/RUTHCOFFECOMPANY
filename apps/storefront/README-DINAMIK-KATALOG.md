# Ruth Istanbul Dinamik Katalog

Kategori ve koleksiyonların tamamı artık panel ve Supabase üzerinden yönetilir.

- **Panel:** `Ürünler → Kategoriler` ve `Ürünler → Koleksiyonlar`
- **Site:** Header alt menüleri, kategori/koleksiyon liste sayfaları ve ürün filtreleri aynı veriyi kullanır.
- **Yeni Gelenler:** Alt menü içermez; ürünlerdeki `is_new` alanından çalışır.
- **WhatsApp:** Panelde `Tema → WhatsApp Destek Butonu` bölümünden yönetilir.

Kurulum için `DINAMIK-KATALOG-KURULUM.txt` dosyasındaki sırayı uygula. SQL dosyası mevcut katalog yapılarını silerek sıfırlar; ürünleri silmez.

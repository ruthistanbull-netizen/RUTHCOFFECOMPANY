# ROSTA Dinamik Katalog

Kategori, koleksiyon ve ürünlerin tamamı ROSTA paneli ve ROSTA Supabase üzerinden yönetilir.

- **Panel:** Ürünler, kategori/koleksiyon yönetimi ve stok ekranları.
- **Storefront:** Menü, kategori/koleksiyon sayfaları, ürün filtreleri ve ürün detayları aynı canlı ROSTA kataloğunu kullanır.
- **Yeni Gelenler:** Ürünlerin `is_new` alanından üretilir.
- **Görseller:** Ürün ve varyant görselleri ROSTA katalog ilişkilerinden okunur.
- **Fallback:** Başka marka veya eski statik ürün kataloğu runtime fallback olarak kullanılmaz.

Production storefront: `https://rostacoffecompany.zeabur.app`

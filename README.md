# Ruth Coffee Company

Frontend-first Ruth Coffee Company storefront adapted from the Ruth Istanbul storefront's visual and motion language.

## Architecture
- Next.js App Router
- Framer Motion interactions and page transitions
- Coffee-specific mock catalog isolated in `src/data/coffee.ts`
- No Ruth Istanbul product/customer/database API dependency
- Backend/panel integration points can later replace the local data layer

## Run
```bash
npm install
npm run dev
```
